How they arrived
How to read this. A “view” is one page load, counted server-side with Google’s clock, bucketed by UTC day. “Unique visitors” counts a browser once per day using a random id in its own localStorage — clearing site data, a different browser or a private window all read as someone new, so treat it as a floor rather than a headcount.

Countries come from an IP lookup made by the visitor’s own browser, because static hosting puts no server of ours in the request path. Ad blockers commonly block that lookup, so some views land under unknown — the time-zone column is derived from the browser itself, never blocked, and is the more reliable of the two for a rough location.

These counts can be inflated by anyone who reads the public repo, until Firebase App Check is switched on. See step 6 of ANALYTICS-SETUP.md.
